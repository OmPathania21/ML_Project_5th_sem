## Repository layout

```
PBL_Reviews/            one folder per review, holding everything we submit or present
  PBL1/
    brief/              what the faculty gave us: dataset list, groups, rubric
    presentation/       slides (.pptx / .pdf)
    report/             report (.docx / .pdf)
  PBL2/ ...             add one of these for each later review

code/                   all code for the project
  data/raw/             downloaded datasets, left unchanged
  data/processed/       cleaned datasets
  notebooks/            Jupyter notebooks (EDA, regression, classification)
  src/                  reusable Python modules
  outputs/figures/      plots used in slides and reports
  outputs/models/       saved models and metric tables
```
